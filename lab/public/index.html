PayPal test checkout

$1.00USD · one-time sandbox payment

The amount is fixed on the server. PayPal credentials and payment capture never run in the browser.

Use a PayPal Sandbox personal buyer account. Never enter a real PayPal password here.

What this lab demonstrates

  1. Browser starts Google OAuth and receives an HttpOnly session cookie.
  2. Cloudflare Function creates a fixed $1 Sandbox order using the secret.
  3. PayPal asks the sandbox buyer to approve the order.
  4. Cloudflare Function captures and validates the order, then records it in D1.
